# PRODUCT.md

## Platform

Web (static site, Astro + React + Tailwind CSS)

## Users

- **Primary:** Recruiters and hiring managers evaluating AI/ML engineering candidates
- **Secondary:** Technical peers, AI researchers, and developers in the community
- **Context:** Visitors arrive from LinkedIn, job applications, or GitHub links. They scan quickly and decide whether to dig deeper within seconds.

## Product Purpose

A personal portfolio that demonstrates Felix Wang's (Yunfei Wang) AI/ML engineering capabilities through real project work, while establishing a long-term professional presence that grows with his career.

## Positioning

An AI engineer's home on the web — technically credible, visually distinctive, and human. Not a template. Not a gimmick.

## Operating Context

- Short-term: Job search tool (M.S. CS student at USC, targeting AI/ML roles)
- Long-term: Evolving personal brand hub (projects, writing, photography)
- Bilingual audience: English primary, Chinese secondary

## Capabilities and Constraints

### Must support
- Bilingual content (English + Chinese) with prefix-based routing
- Project showcase with detail pages
- Photo gallery
- Mobile-responsive layout
- Fast static delivery (Astro SSG)

### Technical stack
- Astro 4.16 + React 18 + Tailwind CSS 3.4
- Framer Motion for page transitions
- Three.js for hero visual effects (Liquid Ether fluid simulation)
- TypeScript throughout

### Constraints
- No backend / no CMS — all content is static
- Must work without JavaScript for core content (progressive enhancement)
- Company network may restrict some external resources

## Brand Commitments

- **Tone:** Professional yet interesting — serious about craft, not about being serious
- **Feeling:** Competent, thoughtful, distinctive
- **Not:** Generic, flashy-for-the-sake-of-it, corporate
- **Typography:** Clean sans-serif (Inter + Noto Sans SC for CJK)
- **Color:** Blue-anchored palette as primary accent

## Evidence on Hand

- 4 featured AI/ML projects (RAG pipeline, ReAct agent, stock forecasting, data annotation)
- Work experience at Corning Incorporated, ShenwanHongyuan Securities, Shanghai University
- M.S. in CS (AI) at USC, B.S. in Math and Data Science
- Photography collection (travel, nature, life)

## Product Principles

1. **Show, don't tell** — Let projects and work speak. Avoid self-promotional language.
2. **Respect attention** — Every section earns its place. No filler, no information overload.
3. **Technical credibility through craft** — The site itself is a demonstration of engineering taste.
4. **Progressive depth** — Quick scan → interested click → deep dive. Layer information, don't dump it.

## Accessibility & Inclusion

- WCAG 2.1 AA minimum
- Keyboard navigation for all interactive elements
- Sufficient contrast ratios
- Reduced-motion preference respected for animations
- Bilingual content with proper lang attributes

## Anti-references

- Typical AI-generated sites (purple gradients, cards-in-cards, no personality)
- Over-designed portfolios (too many animations, distracting, unfocused)
- Information-overloaded pages (cluttered layouts, dense text, exhausting to read)
