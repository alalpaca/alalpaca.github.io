## 🚀 What I Work On

- **End-to-End RAG Knowledge Pipeline** — Automated ingestion/update pipeline integrating Power Automate triggers, MinerU document parsing, and a dual LightRAG / RAG-Anything path, with SQLite-based state tracking, error retry, and file-level node deletion via open-source framework modifications.
- **Industrial PLC Alarm-Diagnosis ReAct Agent** — Built on LangGraph to parse 29 Mitsubishi Q-series PLC subroutines (6,820+ causal edges), tracing alarm causal chains back to the physical I/O layer; delivered as an interactive system with a Gradio frontend and FastAPI backend.
- **Automated Annotation System for Scientific Literature** — Multi-model ensemble (rule-based NLP, BiLSTM-CRF, LLM/OneKE) with a RoBERTa verifier reaching ~83% precision, deployed to production with Django + Vue3. Published in **arXiv:2505.19879**.
- **Multimodal Short-Term Stock Forecasting** — Combined financial news (FinBERT), market data, and technical indicators through temporal networks (LSTM/GRU/TCN) and cross-attention fusion.
